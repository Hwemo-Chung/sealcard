## 간단한 설명 (최대 80자)
```
사진을 밀봉하고, 바인더에 꽂아 남깁니다.
```
(글자 수: 24 · 여유 있음)

## 자세한 설명 (최대 4000자)
```
찍고, 밀봉하고, 바인더에 꽂습니다.

Sealcard는 사진을 카드로 밀봉해 바인더에 남기는 앱입니다.
밀봉 후에는 그 카드를 다시 고칠 수 없습니다. 한 장 한 장이 그대로 남습니다.

• 카메라로 촬영해 즉시 밀봉
• 프레임 템플릿(폴라로이드, 필름, 우표 등)과 날짜·위치·바인더 제목 스탬프
• 바인더로 카드 정리·이동
• 이미지 공유(시스템 공유 시트)
• 배경화면용으로 갤러리에 저장

모든 사진은 기기 안에만 보관됩니다.
계정 없음, 클라우드 없음, 광고 없음.

권한
• 카메라: 사진 촬영에 사용
• 위치(선택): 장소 스탬프를 켤 때만, 기기 안에서만 처리
• 사진 저장: 사용자가 배경화면용으로 저장할 때만

개인정보처리방침
https://hwemo-chung.github.io/sealcard-privacy.html
```

# English (언어 추가)

## App name
```
Sealcard
```

## Short description (max 80)
```
Seal a photo. Keep it in a binder.
```

## Full description (max 4000)
```
Shoot. Seal. File it in a binder.

Sealcard turns a photo into a sealed card and keeps it in a binder.
Once sealed, a card cannot be edited. What you kept stays as it was.

• Capture with the camera and seal immediately
• Frame templates (polaroid, film, postage, and more) with date, place, and binder-title stamps
• Organize cards in binders; move between binders
• Share as an image (system share sheet)
• Save an image for wallpaper

Everything stays on your device.
No account, no cloud, no ads.

Permissions
• Camera: used to take photos
• Location (optional): only when place stamp is on; processed on-device only
• Photos write: only when you choose to save for wallpaper

Privacy policy
https://hwemo-chung.github.io/sealcard-privacy.html
```

撮って、封じて、バインダーに残します。

Sealcardは、写真をカードとして封じてバインダーに残すアプリです。

• カメラで撮影してすぐに封じる
• フレーム（ポラロイド、フィルム、切手など）と日付・場所・バインダータイトルのスタンプ

権限
• カメラ：撮影に使用
• 位置情報（任意）：場所スタンプをオンにしたときのみ。端末内のみで処理
• 写真の書き込み：壁紙用に保存するときのみ
