# Sealcard — Play listing (JA)

## App name
Sealcard

## Short description
写真を封じて、シリーズのバインダーに残します。

## Full description
撮って、封じて、バインダーに残します。

Sealcardは、写真をカードとして封じてシリーズのバインダーに残すアプリです。一度封じたカードは編集できません。残した一枚がそのまま残ります。

• カメラで撮影してすぐに封じる
• フレームのテンプレートと日付
• バインダーでシリーズを整理
• 画像として共有（システムの共有シート）
• 壁紙用にギャラリーへ保存

写真はすべて端末内にのみ保存されます。アカウントなし、クラウドなし、広告なし。

権限
• カメラ：撮影に使用
• 写真の書き込み：壁紙用に保存するときのみ
