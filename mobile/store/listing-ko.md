## Short description

## Full description
찍고, 밀봉하고, 바인더에 꽂습니다.

Sealcard는 사진을 카드로 밀봉해 시리즈 바인더에 남기는 앱입니다. 밀봉 후에는 그 카드를 다시 고칠 수 없습니다. 한 장 한 장이 그대로 남습니다.

• 카메라로 촬영해 즉시 밀봉
• 프레임 템플릿과 날짜 표기
• 바인더로 시리즈 정리
• 이미지 공유(시스템 공유 시트)
• 배경화면용으로 갤러리에 저장

모든 사진은 기기 안에만 보관됩니다. 계정 없음, 클라우드 없음, 광고 없음.

권한
• 카메라: 사진 촬영에 사용
• 사진 저장: 사용자가 배경화면용으로 저장할 때만
