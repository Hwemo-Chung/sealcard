# Play Console — 앱 콘텐츠 선언 전체 답안 (Sealcard)

Play Console → **정책 및 프로그램 → 앱 콘텐츠**의 모든 섹션 답안.
스토어 등록정보(이름/설명/그래픽)는 [play-console-default-listing.md](./play-console-default-listing.md) 참조.

**패키지:** `app.sealcard.mobile` · **버전:** 1.0.0
**연락 이메일:** `tolaria@naver.com`
**개인정보처리방침:** https://hwemo-chung.github.io/sealcard-privacy.html (라이브 확인됨, HTTP 200)

---

## 0. 앱 매니페스트 권한 (선언 근거)

`app.json` 기준 최종 권한. 선언 답안은 이 목록과 반드시 일치해야 함.

| 권한 | 출처 | 용도 |
|------|------|------|
| `CAMERA` | expo-camera | 카드로 밀봉할 사진 촬영 (핵심 기능) |
| `ACCESS_COARSE_LOCATION` / `ACCESS_FINE_LOCATION` | expo-location | 선택 기능 — 장소 스탬프 켤 때만 포그라운드 1회 조회 + 기기 내 역지오코딩 |
| `READ_MEDIA_IMAGES`<br>`READ_MEDIA_VISUAL_USER_SELECTED` | expo-media-library | 저장한 이미지를 앱 앨범(Sealcard)에 넣기 위한 접근 |
| `READ_EXTERNAL_STORAGE` / `WRITE_EXTERNAL_STORAGE` | expo-media-library | Android 12 이하 저장 경로 |

**없는 권한 (선언 시 근거):** `RECORD_AUDIO` 없음(오디오 녹음 안 함), `READ_MEDIA_VIDEO`/`READ_MEDIA_AUDIO` 없음, `AD_ID` 없음, 백그라운드 위치 없음, `QUERY_ALL_PACKAGES` 없음.

## 6. 사진 및 동영상 권한 선언 (Photo and Video Permissions)

`READ_MEDIA_IMAGES` 선언으로 인해 **필수 폼**.

| 항목 | 답 |
|------|-----|
| 앱의 핵심 목적에 사진 접근이 필요한가? | **예** |
| 사용 사례 | 사용자가 밀봉한 카드 이미지를 기기 갤러리에 저장하고, 앱 전용 앨범(`Sealcard`)에 정리하기 위해 |
| 광범위한 접근(전체 라이브러리) 필요 사유 | 저장한 에셋을 앱 앨범으로 이동·확인하기 위해 미디어 스토어 접근이 필요. 사용자 사진을 읽어 업로드·분석하지 않음 |
| 일회성/드문 접근인가? | 아니요 — 사용자가 저장을 실행할 때마다 발생 |
| Android Photo Picker로 대체 가능한가? | 아니요 — 읽기가 아닌 **쓰기·앨범 정리** 목적 |
| 데이터 전송 | **없음** — 기기 외부로 전송하지 않음 |

> 데모 영상을 요구할 경우: 카드 상세 → **배경화면으로** 저장 → 갤러리의 `Sealcard` 앨범에 나타나는 흐름을 녹화.

## 11. 제출 순서

1. Play Console → 앱 만들기: 이름 `Sealcard`, 기본 언어 한국어, 앱/무료
2. **앱 콘텐츠** 섹션 위 답안대로 전부 완료 (1~8)
3. **스토어 등록정보** — `play-console-default-listing.md` 붙여넣기 + 그래픽 업로드
4. 국가·가격 설정 (9)
5. AAB 업로드 → 내부 테스트 트랙 → 테스터(본인 Gmail) 추가
6. 내부 테스트 링크로 설치 → 카드 1장 밀봉 · 저장 · 공유 · 언어 전환 확인
7. 프로덕션 승격 (단계적 출시 선택 가능)

### AAB 업로드 경로 (택1)

- **수동:** Play Console에 `.aab` 직접 업로드 (서비스 계정 불필요)
- **자동:** `mobile/play-service-account.json` 배치 후 `eas submit -p android --profile production`
  → 서비스 계정 생성: Play Console → 설정 → API 액세스 → Google Cloud 프로젝트 연결 → 서비스 계정 생성 → 역할 "테스트 및 출시 관리" → JSON 키 다운로드
